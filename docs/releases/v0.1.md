# Kajo 0.1

Kajo-0.1.dmg: the Kajo app (the tools on the development image, File > New App..., the kajo CLI),
the Kajo checkout of v0.1 (8b11e25c97aa4a30ee808e170655441bdbccd9f8) and the prebuilt Kajo frameworks for macOS arm64 and iOS arm64.
Apple silicon Macs, macOS 15 or later; Xcode for building apps. SHA-256 in Kajo-0.1.dmg.sha256.
Signed with a Developer ID and notarized; Gatekeeper accepts the app and the dmg.

## What is in it

The first release of Kajo: a Smalltalk with a VM in Swift and native AppKit and UIKit shells.

- The VM core (`docs/PLAN.md`, declared done 2026-11-07): an object table, per-worker nurseries, concurrent marking and lazy sweeping, concurrent relocation, young collection without stopping the world, large objects, a bytecode set with 17 fused instructions, images with saved Processes.
- The kernel in Smalltalk (`kernel/`, 211 SUnit tests) and the developer tools (`tools/`: browser, workspace, inspector, debugger, test runner, transcript, target picker) on the development image the app opens.
- The development protocol over Unix sockets and TCP with Bonjour, the debugger with stepping and define-and-proceed, `kajo mcp` for agents, `kajo eval|compile|browse|debug|test`.
- `kajo new <Name> --bundle-id <id>` (File > New App... in the app): an xcodegen project with a Mac and an iOS target over one Tonel directory, Debug serving the tools over TCP and Bonjour, Release a sealed image with no development code in the binary, both linking the prebuilt frameworks.
- The performance report: `docs/performance/README.md`.

## Known

- Developer ID signing and notarization ran on the mini from a keychain profile; nothing is built in CI.
- Generated projects pin the checkout the app copies to `~/Library/Application Support/Kajo/0.1/`.
- Not in this release: simulator and Intel slices, an updater, PSK-TLS for the phone transport.
