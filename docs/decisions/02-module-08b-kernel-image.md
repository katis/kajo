# Module 8b: the kernel image

The Smalltalk side built in module 8b: a kernel of 123 classes and 1368
methods written from scratch in Tonel, a bootstrap compiler in Swift sharing
kasm's encoder and verifier, a compiler in Smalltalk that agrees with the
bootstrap on every method of the image, the weak symbol table, the image
build at 2.5 MB, SUnit with the v1 NDJSON event stream and JUnit XML, and
the Smalltalk kernels at 0.88 to 1.03 of their kasm twins; 8b left class
variables, a method-install primitive, saved Processes (8c), Unicode tables
and the main-thread check undone, and its five open questions in
`docs/modules/kernel-image.md` await the owner.
