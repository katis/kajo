Answered by the owner on 2026-11-15, asked one by one in the session:

1. Native code in a Release build: on by default. This differs from what
   was built (`KAJO_NATIVE: NO` unless `kajo new --native`) and from the
   recommendation; it becomes a follow-up (`docs/PLAN.md`), and the part 5
   items left unmeasured (frames missed with the module on, the scenario
   matrix and the kernel's tests through the Sample) now concern the
   default path of every Release app.
2. The size rule: 0.9 of full speed kept, as recommended.
3. The subset `callees` stays in the default, as recommended, until AOT 3's
   profile replaces it.
4. The module's place: in the app binary, as recommended.
5. Narrower per-pc tables: built with AOT 3, as recommended.
